# IMDb Sentiment Analysis

## Project Overview

This project performs sentiment analysis on IMDb movie reviews using Python and TextBlob. The reviews are classified as Positive, Negative, or Neutral based on their sentiment polarity.

## Features

* Reads IMDb review dataset
* Performs sentiment analysis using TextBlob
* Classifies reviews into Positive, Negative, and Neutral categories
* Displays sentiment distribution
* Generates insights from review data

## Technologies Used

* Python
* Pandas
* TextBlob

## Dataset

IMDb Movie Reviews Dataset

## Output

* Total reviews analyzed
* Number of positive reviews
* Number of negative reviews
* Number of neutral reviews

## How to Run

1. Install required libraries:
   pip install pandas textblob

2. Place the dataset file in the project folder.

3. Run:
   python sentiment_analysis.py

## Conclusion

The project helps understand audience opinions and sentiment trends from movie reviews using Natural Language Processing techniques.
