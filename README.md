# Titanic Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to identify patterns, trends, and insights related to passenger survival.

## Features

* Dataset exploration
* Missing value analysis
* Statistical summary
* Survival analysis
* Data insights generation

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Dataset

Titanic Dataset

## Analysis Performed

* Total passengers
* Survival count
* Gender-wise survival
* Passenger class analysis
* Age distribution

## How to Run

1. Install required libraries:
   pip install pandas matplotlib seaborn

2. Place Titanic-Dataset.csv in the project folder.

3. Run:
   python eda.py

## Key Findings

* Female passengers had higher survival rates.
* First-class passengers survived more frequently.
* Most passengers were between 20 and 40 years old.

## Conclusion

EDA helps uncover hidden patterns and provides valuable insights for decision-making and further predictive analysis.
