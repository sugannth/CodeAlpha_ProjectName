# Netflix Data Visualization

## Project Overview

This project transforms raw Netflix dataset information into meaningful visualizations to better understand content distribution and trends.

## Features

* Movies vs TV Shows comparison
* Country-wise content analysis
* Genre distribution
* Release year trends
* Graphical representation of data

## Technologies Used

* Python
* Pandas
* Matplotlib

## Dataset

Netflix Titles Dataset

## Visualizations Created

* Bar Charts
* Histograms
* Pie Charts
* Trend Analysis Graphs

## How to Run

1. Install required libraries:
   pip install pandas matplotlib

2. Place netflix_titles.csv in the project folder.

3. Run:
   python visualization.py

## Insights

* Distribution of Movies and TV Shows
* Most active content-producing countries
* Popular genres on Netflix
* Growth of content over the years

## Conclusion

Data visualization converts complex data into clear graphical insights, making analysis easier and more effective.
